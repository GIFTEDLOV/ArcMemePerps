# Incident response

1. Mark the affected provider or protocol component degraded, stale, or critical.
2. Stop risk-increasing execution through the execution gate.
3. Use emergency controls only to reduce leverage/OI, pause, or close-only.
4. Preserve provider evidence, chain checkpoint, tx hash, and canonical event.
5. Reconcile custody, OI, insurance, bad debt, and qualification state.
6. Resume only after fresh evidence and an authorized configuration change.

No emergency path may increase exposure or rewrite a reconciliation mismatch.
