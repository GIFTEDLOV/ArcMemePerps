# ArcMemePerps backend feature matrix

This is the binding Gate 4D implementation ledger. A row is `IMPLEMENTED` only
when the execution path exists in source and has a deterministic test or
recorded read-only evidence. A schema, interface, fixture, or empty provider
branch alone is not implementation. `EXTERNAL_BLOCKED` means the repository
has a safe, explicit unavailable path and the missing capability depends on an
external credential, documented venue contract, or third-party service.

## Counts

The command `pnpm backend:frontend-readiness` parses this table and fails on
any `PARTIAL` or `NOT_IMPLEMENTED` row. Totals in reports must equal the rows
above. Current totals are: `TOTAL=84`, `IMPLEMENTED=56`, `PARTIAL=21`,
`NOT_IMPLEMENTED=0`, `EXTERNAL_BLOCKED=5`, `RELEASE_ONLY=2`. This document
intentionally exposes incomplete submission capabilities.

## No-mock audit

`MockUSDC`, injected HTTP transports, fixture adapters, and
`packages/simulator` are test/analysis facilities. No production adapter turns
an unavailable provider into zero, simulated evidence, or a qualification
pass. Read-only quote math is not a transaction fallback.
