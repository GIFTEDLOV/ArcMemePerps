This is the Gate 4C source-of-truth ledger. `IMPLEMENTED` means a real execution path exists and has deterministic tests or recorded runtime evidence. Interfaces, fixtures, analytical simulations, and unavailable-provider branches are not counted as implementation of the live capability.

## No-mock / no-fallback audit

- `contracts/test/MockUSDC.sol` and injected `fakeFetch` functions are test-only.
- `packages/simulator` is an analytical stress package, not a provider fallback.
- `packages/market-depth` calls quote math a simulation because it is an `eth_call`-equivalent calculation, not a transaction; unsupported venues return `UNAVAILABLE`.
- `packages/chain-adapters/src/live.ts` no longer returns empty arrays or `UNKNOWN` pool records for unsupported capabilities; those calls raise `CapabilityUnavailableError`.
- `UNKNOWN`, `UNAVAILABLE`, and `ERROR` are preserved as evidence/provider states. The risk engine's incomplete-evidence gate prevents those states from passing integrity qualification.
- `.env.example` contains a commented placeholder variable only; no credential value is present.

## Canonical data rule

`MarketSnapshotSchema` is the versioned boundary for future API, notification, competition, agent, and frontend consumers. It uses fixed-point decimal strings for monetary values and rejects unknown fields. Existing legacy `MarketIntelligenceRecord` fields are retained for Gate 1 compatibility and are not sufficient by themselves to claim canonical product completeness until a snapshot assembler and durable ingestion scheduler are connected.
