convenience API is not treated as a blocker when the same fact can be read from
documented chain contracts, events, or an official SDK.

## Credentialed enrichment

Helius, GoPlus, and Bubblemaps remain optional enrichment providers. Missing
credentials do not block ordinary token/venue reads, but a risk tier that
requires a particular evidence class remains `WATCH`/`BLOCKED`; missing data is
never converted into a pass. There are no remaining planned submission rows in
`EXTERNAL_BLOCKED`.
